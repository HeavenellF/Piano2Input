# Piano2Input

A python script to translate Digital Piano into keyboard input

## How to use :
Just run it!

use key_layout and start_note to map your piano - keyboard input
Exampe :

```
key_layout = "ABCD"
start_note = 48  # C2
```

- If you pressed C2, it will give input "A"
- If you pressed C#/Db, it will give input "B"
and so.
